# Changelog

## 0.1.0

- Zstandard buffer and Web Streams APIs for browsers, Web Workers, and Node.js 24+.
- Native gzip, deflate, and raw deflate through the same asynchronous API.
- A reusable synchronous Zstd codec and optional dedicated or pooled Worker execution.
- Cancellation, byte limits, and Zstd support for dictionaries, checksums, and frame content size.
